# JafrMysticPagesPro

سایت استاتیک فارسی برای محاسبهٔ ابجد کبیر و تکسیرهای جفری.

## انتشار روی GitHub Pages
1. مخزن جدید در GitHub بسازید.
2. محتوای این پروژه را در **ریشهٔ مخزن** آپلود کنید.
3. مطمئن شوید `index.html` در ریشه قرار دارد.
4. به `Settings > Pages` بروید.
5. گزینهٔ `Deploy from a branch` را انتخاب کنید.
6. شاخهٔ `main` و پوشهٔ `/(root)` را انتخاب و ذخیره کنید.
7. چند دقیقه صبر کنید تا لینک سایت فعال شود.

## ساختار پروژه
- `index.html`
- `styles.css`
- `app.js`
- `assets/hero-bg.png`

## نکته
اگر فایل‌ها داخل یک پوشهٔ اضافی آپلود شوند، باید در تنظیمات Pages همان پوشه را مبنا قرار دهید یا فایل‌ها را به ریشه منتقل کنید.
